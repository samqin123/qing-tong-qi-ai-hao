# 动态书目与原始资料目录

> 本目录随研究持续更新。原始文件尽量保留来源文件名，并按国别/专题分类；使用时回到报告中的引文和原始出版信息核对。PDF 由 Git LFS 管理。

## 收录原则

- 优先收集考古发掘报告、博物馆图录与馆藏页、学术专著和论文。
- 记录来源、作者、出版信息、原文链接、阅读用途与版权许可；未核实的材料标记为线索，不作为结论。
- 公开引用优先指向原始出版方或机构页面；原始文件收录不改变其既有版权。
