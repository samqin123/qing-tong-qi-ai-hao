## 资料整理约定

- 记录器名、出土地点、墓葬年代、铭文及收藏机构。
- 说明“楚式”“周礼”“升鼎”等概念的定义依据。
- 不把政治中心、文化中心和铸造中心自动视为同一地点。
- 引用优先采用考古报告、博物馆/研究机构资料和正式论文，并保存链接与访问日期。
- 古国专题采用[西周古国调研技能](.codex/skills/western-zhou-states/SKILL.md)：区分发掘时间与墓葬年代，逐项标注可信度，并为重要器物记录铭文、纹饰、图像与收藏信息。
